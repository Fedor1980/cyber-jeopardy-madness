## 🎮 Game Controls

### Ultimate Cyber Jeopardy

**Keyboard Controls:**
- `Q` - Player 1 buzz in
- `W` - Player 2 buzz in
- `E` - Player 3 buzz in
- `Tab` - Navigate options
- `Enter` - Select option
- `Space` - Confirm

**Mouse Controls:**
- Click question tiles to select
- Click answer options
- Click buttons to proceed

**Gameplay:**
1. Enter player names and select industry
2. Random player goes first
3. Select a question tile (category + value)
4. Read question, select answer within 15 seconds
5. Correct = keep control, Incorrect = others can buzz in
6. Play through 3 rounds
7. Final Jeopardy: Place wager and answer

---

### CyberClarity

**Controls:**
- Click cards to flip and reveal questions
- Select answer from multiple choice
- Click "Next" to continue
- Track your progress on screen

## ❓ Troubleshooting

**Q: The game won't open**
- A: Make sure you saved the file with `.html` extension
- A: Try opening with a different browser (Chrome, Firefox, Edge)
- A: Right-click the file → Open With → [Your Browser]

**Q: Can I play offline?**
- A: Yes! Once downloaded, the games work completely offline

**Q: Can I share with my team?**
- A: Yes! Either share the HTML file or enable GitHub Pages and share the URL

**Q: How do I update questions?**
- A: Edit the `game_questions.json` file or modify the embedded questions in the HTML

**Q: Does it work on mobile?**
- A: Yes! Both games are mobile-responsive

**Q: Do I need to install anything?**
- A: No! Just a modern web browser (Chrome, Firefox, Safari, Edge)

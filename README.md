# Cyber Jeopardy Madness

A team-based cybersecurity awareness training game built for Federal Credit Unions.
Features a Jeopardy-style format, GPT integration, and bracket-based coworker competition.

## Setup

1. Install dependencies: `npm install`
2. Run locally: `npm start`
3. Deploy: Vercel, Firebase, or GitHub Pages

Questions and game logic stored in /logic
Assets and visuals in /public/assets

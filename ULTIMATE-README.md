## 🎮 How to Play

### Setup Phase
1. **Select Players:** Choose 2-4 operatives
2. **Enter Names:** Give each player a unique callsign
3. **Configure AI** (optional): Enable hints and add OpenAI API key
4. **Start Mission:** Launch the game!

### Gameplay
1. **Starting Player:** Randomly selected
2. **Select Question:** Click any blue tile on the board
3. **Answer Timer:** 15 seconds to answer
4. **Multiple Choice:** Pick from 4 options
5. **Buzz-In:** If wrong, others can buzz in (Q/W/E/R keys)
6. **Daily Doubles:** Hidden questions with custom wagering
7. **Winner Continues:** Correct answer = you keep picking
8. **Round Progression:** Complete Round 1 → Round 2 → Winner!

### Scoring
- **Round 1:** $100 - $500 per question
- **Round 2:** $200 - $1000 per question (values doubled)
- **Correct:** Add question value to score
- **Incorrect:** Lose question value from score
- **Daily Double:** Custom wager (min $5, max = score or $1000/$2000)

### AI Hints
- **3 Hints Per Game:** Use strategically
- **Click Hint Button:** During any question
- **Educational:** Learn without spoiling the answer
- **Requires:** OpenAI API key configured

2. ACCESS THE API
-------------------------------------------------------------------------------

{{- if .Values.ingress.enabled }}
Your API is accessible via Ingress at:

{{- range .Values.ingress.hosts }}
  https://{{ .host }}
{{- end }}

{{- else if eq .Values.scrollApi.service.type "LoadBalancer" }}
Get the LoadBalancer IP:
  kubectl get svc {{ include "sovereign-scroll.fullname" . }}-api -n {{ .Release.Namespace }}

Access the API:
  export SERVICE_IP=$(kubectl get svc {{ include "sovereign-scroll.fullname" . }}-api -n {{ .Release.Namespace }} -o jsonpath='{.status.loadBalancer.ingress[0].ip}')
  curl -H "X-API-Key: {{ .Values.scrollApi.apiKey }}" http://$SERVICE_IP:{{ .Values.scrollApi.service.port }}/health

{{- else }}
Port-forward to access the API locally:
  kubectl port-forward svc/{{ include "sovereign-scroll.fullname" . }}-api {{ .Values.scrollApi.service.port }}:{{ .Values.scrollApi.service.port }} -n {{ .Release.Namespace }}

Then access:
  curl -H "X-API-Key: {{ .Values.scrollApi.apiKey }}" http://localhost:{{ .Values.scrollApi.service.port }}/health
{{- end }}

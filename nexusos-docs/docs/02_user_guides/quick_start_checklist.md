# NexusOS Quick Start Checklist

This condensed checklist gets you up and running quickly. For detailed explanations, see the [User Onboarding Guide](./user_onboarding_guide.md).

## Account Setup (5 minutes)

### ☐ Create Your Account
- [ ] Sign up at [nexusos.io/signup](https://nexusos.io/signup)
- [ ] Verify your email address
- [ ] Complete your profile
- [ ] Choose your subscription tier

### ☐ Configure Workspace
- [ ] Name your workspace
- [ ] Select default region
- [ ] Enable two-factor authentication
- [ ] Set notification preferences

### ☐ Add Payment Method
- [ ] Navigate to Settings → Billing
- [ ] Add credit card or payment method
- [ ] Set up usage alerts at 80% of quota
- [ ] Review pricing for your tier

## First Agent (3 minutes)

### ☐ Create Agent
- [ ] Click "New Agent" from dashboard
- [ ] Choose agent type (start with Conversational)
- [ ] Name: "My First Agent"
- [ ] Select model: nexus-gpt-3.5
- [ ] Set temperature: 0.7
- [ ] Write system prompt

### ☐ Configure Agent
- [ ] Set max tokens: 500
- [ ] Add description
- [ ] Add tags for organization
- [ ] Enable memory (optional)

### ☐ Test Agent
- [ ] Click "Test Agent"
- [ ] Try 3-5 test inputs
- [ ] Verify responses
- [ ] Adjust parameters if needed

### ☐ Deploy Agent
- [ ] Save agent
- [ ] Set to "Active" status
- [ ] Configure execution limits
- [ ] Set access permissions

## First Workflow (Optional, 5 minutes)

### ☐ Create Workflow
- [ ] Navigate to Workflows
- [ ] Click "New Workflow"
- [ ] Choose trigger type (Webhook or Schedule)
- [ ] Name your workflow

### ☐ Add Steps
- [ ] Add at least 2 steps
- [ ] Configure step dependencies
- [ ] Set error handling
- [ ] Add variables as needed

### ☐ Test and Deploy
- [ ] Run test execution
- [ ] Verify all steps complete
- [ ] Check outputs
- [ ] Activate workflow

## Team Setup (If applicable, 2 minutes)

### ☐ Invite Team Members
- [ ] Go to Settings → Team
- [ ] Click "Invite Member"
- [ ] Enter email addresses
- [ ] Assign appropriate roles
- [ ] Send invitations

### ☐ Configure Permissions
- [ ] Review default role permissions
- [ ] Set resource sharing defaults
- [ ] Configure audit logging

## Integrations (Optional, 5 minutes)

### ☐ Connect Services
- [ ] Navigate to Settings → Integrations
- [ ] Connect Slack (if applicable)
- [ ] Connect email provider
- [ ] Connect cloud storage
- [ ] Test connections

## Security Checklist

### ☐ Essential Security
- [ ] Enable 2FA on your account
- [ ] Use strong, unique password
- [ ] Review active sessions
- [ ] Set up API key if needed
- [ ] Configure IP whitelisting

### ☐ Optional Security
- [ ] Set up SSO (Enterprise)
- [ ] Configure data retention policies
- [ ] Enable audit logging
- [ ] Review compliance settings

## Monitoring Setup

### ☐ Configure Alerts
- [ ] Set budget alert at 80%
- [ ] Enable execution failure notifications
- [ ] Set up performance degradation alerts
- [ ] Configure security alerts

### ☐ Dashboard Customization
- [ ] Add favorite widgets
- [ ] Arrange dashboard layout
- [ ] Set default filters
- [ ] Bookmark important pages

## Quick Reference

### Keyboard Shortcuts
- `Cmd/Ctrl + K` - Search
- `Cmd/Ctrl + N` - New agent
- `Cmd/Ctrl + S` - Save
- `Cmd/Ctrl + /` - Show shortcuts

### Support Resources
- **Documentation**: [docs.nexusos.io](https://docs.nexusos.io)
- **Email**: support@nexusos.io
- **Chat**: Available in platform
- **Status**: [status.nexusos.io](https://status.nexusos.io)

### Common Tasks

**Create Agent**: Dashboard → New Agent
**Create Workflow**: Workflows → New Workflow
**View Usage**: Settings → Billing
**Invite User**: Settings → Team → Invite
**API Keys**: Settings → API Keys → Generate

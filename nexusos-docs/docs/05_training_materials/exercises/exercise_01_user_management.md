# Exercise 1: User Management

## Objectives
- Create users via CLI and admin console
- Configure roles and permissions
- Manage API keys
- Test access controls

## Steps

### Part 1: Create Users (10 min)
1. Create 3 users with different roles
2. Send invitation emails
3. Verify users in admin console

### Part 2: API Keys (10 min)
1. Generate API key for a user
2. Test API key with curl
3. Revoke API key
4. Verify revocation

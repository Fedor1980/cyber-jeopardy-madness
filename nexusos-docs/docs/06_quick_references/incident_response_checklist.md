# Incident Response Checklist

## P0 Critical Incident

- [ ] Declare incident in #incidents channel
- [ ] Create war room
- [ ] Assign Incident Commander
- [ ] Update status page (major outage)
- [ ] Notify leadership
- [ ] Begin diagnosis
- [ ] Implement mitigation
- [ ] Monitor metrics
- [ ] Customer communication (every 30 min)
- [ ] Document timeline
- [ ] Verify resolution
- [ ] Close incident
- [ ] Schedule post-mortem (within 5 days)

## P1 High Priority

- [ ] Create incident ticket
- [ ] Notify on-call engineer
- [ ] Update status page (partial outage)
- [ ] Diagnose issue
- [ ] Implement fix
- [ ] Monitor for 1 hour
- [ ] Customer communication
- [ ] Close ticket
- [ ] Optional post-mortem

## Security Breach

- [ ] Isolate affected systems
- [ ] Block attacker IPs
- [ ] Revoke compromised credentials
- [ ] Preserve evidence
- [ ] Contact security team
- [ ] Contact legal (if required)
- [ ] Assess data exposure
- [ ] Notify users (if required)
- [ ] Implement remediation
- [ ] Security post-mortem

# NexusOS Color Palette

## Primary Colors

**Indigo** - Primary brand color
- Hex: #6366F1
- RGB: 99, 102, 241
- Use: Primary buttons, links, brand elements

**Deep Indigo**
- Hex: #4F46E5
- RGB: 79, 70, 229
- Use: Hover states, emphasis

## Secondary Colors

**Emerald** - Success
- Hex: #10B981
- RGB: 16, 185, 129

**Amber** - Warning
- Hex: #F59E0B
- RGB: 245, 158, 11

**Red** - Error/Critical
- Hex: #EF4444
- RGB: 239, 68, 68

## Neutral Colors

- Gray 900: #111827 (Text)
- Gray 700: #374151 (Secondary text)
- Gray 300: #D1D5DB (Borders)
- Gray 100: #F3F4F6 (Backgrounds)
- White: #FFFFFF

## Usage Guidelines
- Use primary colors for brand elements
- Use secondary colors for status indicators
- Maintain 4.5:1 contrast ratio for accessibility

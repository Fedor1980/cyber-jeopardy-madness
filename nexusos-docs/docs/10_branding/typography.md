# Typography

## Fonts

### Primary Font: Inter
- Headings: Inter Bold (700)
- Body: Inter Regular (400)
- Code: Inter Medium (500)

Download: https://fonts.google.com/specimen/Inter

### Monospace: JetBrains Mono
For code blocks and technical content.

## Type Scale

**Headings**:
- H1: 2.5rem (40px) - Page titles
- H2: 2rem (32px) - Section headers
- H3: 1.5rem (24px) - Subsections
- H4: 1.25rem (20px) - Card titles
- H5: 1rem (16px) - Labels
- H6: 0.875rem (14px) - Meta info

**Body**:
- Large: 1.125rem (18px) - Intro text
- Normal: 1rem (16px) - Body copy
- Small: 0.875rem (14px) - Captions

**Code**:
- Inline: 0.875rem (14px)
- Block: 0.875rem (14px), line-height 1.6

## Line Height
- Headings: 1.2
- Body: 1.5
- Code: 1.6

## Best Practices
- Never use more than 2-3 font weights
- Maintain consistent hierarchy
- Use proper line length (45-75 characters)

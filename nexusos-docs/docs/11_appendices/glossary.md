# NexusOS Glossary

## A
**Agent** - An autonomous AI entity that performs specific tasks  
**API** - Application Programming Interface  
**API Key** - Authentication credential for API access  
**Auto-scaling** - Automatic adjustment of resources based on demand

## B
**Backup** - Copy of data for recovery purposes  
**Baseline** - Normal operating metrics for comparison

## C
**Cache** - Temporary storage for frequently accessed data  
**Circuit Breaker** - Pattern to prevent cascade failures  
**CLI** - Command Line Interface

## D
**DR** - Disaster Recovery  
**Downtime** - Period when service is unavailable

## E
**Escalation** - Process of raising incident priority  
**Execution** - Single run of an agent

## F
**Failover** - Switching to backup system  
**FIDO2** - Fast Identity Online authentication standard

## G
**GraphQL** - Query language for APIs

## H
**HA** - High Availability  
**HIPAA** - Health Insurance Portability and Accountability Act

## I
**Incident** - Unplanned service disruption  
**Integration** - Connection between systems

## M
**MFA** - Multi-Factor Authentication  
**Monitoring** - Continuous observation of system health

## O
**OAuth** - Open Authorization standard  
**OpenAPI** - API specification format

## P
**P0/P1/P2** - Incident severity levels  
**Post-mortem** - Analysis after incident resolution

## R
**Rate Limit** - Restriction on request frequency  
**RBAC** - Role-Based Access Control  
**REST** - Representational State Transfer  
**RTO** - Recovery Time Objective  
**RPO** - Recovery Point Objective

## S
**SaaS** - Software as a Service  
**SLA** - Service Level Agreement  
**SSO** - Single Sign-On

## T
**TLS** - Transport Layer Security  
**TOTP** - Time-based One-Time Password

## W
**Webhook** - HTTP callback for event notifications  
**Workflow** - Sequence of automated actions

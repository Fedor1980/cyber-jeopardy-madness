## Storyboard Notes

### Visual Style
- **Clean:** Minimal UI, focus on product
- **Modern:** Smooth transitions, professional
- **Fast-paced:** Quick cuts, no dead time
- **Branded:** Consistent colors (#6366f1)

### Camera Angles
- **Screen recordings:** 1920x1080, 60fps
- **Face cam:** 1080p, well-lit
- **B-roll:** High quality, relevant

### Audio
- **Voiceover:** Clear, enthusiastic, professional
- **Music:** Upbeat, modern, not overpowering
- **SFX:** Subtle UI sounds, keyboard clicks

### Text Overlays
- **Font:** Inter or similar modern sans-serif
- **Size:** Large enough to read on mobile
- **Animation:** Fade in/out, slide up
- **Color:** High contrast, brand colors

## Equipment Recommendations

### Minimum Setup
- **Screen recording:** OBS Studio (free)
- **Video editing:** DaVinci Resolve (free)
- **Microphone:** Built-in (acceptable for demos)
- **Lighting:** Natural window light

### Professional Setup
- **Screen recording:** ScreenFlow or Camtasia
- **Video editing:** Adobe Premiere Pro
- **Microphone:** Blue Yeti or Rode NT-USB
- **Lighting:** Ring light or key/fill lights
- **Camera:** Webcam or DSLR

---

## Recording Tips

### Before Recording
1. Clean up desktop
2. Close unnecessary apps
3. Set browser zoom to 100%
4. Disable notifications
5. Test audio levels
6. Prepare script

### During Recording
1. Speak clearly and slowly
2. Pause between sections
3. Record in segments
4. Leave extra footage
5. Multiple takes if needed

### After Recording
1. Edit tightly (no dead time)
2. Add captions/subtitles
3. Color correction
4. Audio normalization
5. Export in multiple formats (16:9, 1:1, 9:16)

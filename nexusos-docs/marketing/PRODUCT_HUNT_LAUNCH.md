### First Comment Template

```markdown
👋 Hey Product Hunt! I'm [Your Name], and I'm excited to share NexusOS Documentation Platform!

## 🎯 What is it?

A complete documentation system that transforms your markdown files into:
- 📄 Beautiful, responsive HTML sites
- 🔍 Searchable documentation (client-side, no backend!)
- 🌙 Dark mode with theme persistence
- 📊 Auto-rendered diagrams (Mermaid)
- 📑 Professional PDFs (with branding options)
- 🎓 Presentation slides (Marp-powered)

## 💡 Why we built this

We were frustrated with:
- Complex documentation tools that take days to set up
- Expensive SaaS platforms with vendor lock-in
- Lack of customization in open-source options
- No built-in search that actually works

So we built NexusOS Docs: **zero config, maximum features**.

## ✨ Cool Features

**Interactive Search**
- Press `/` to search instantly
- Fuzzy matching (finds results even with typos)
- Keyboard navigation
- No backend required!

**Dark Mode**
- Automatic system detection
- Manual toggle
- Persists across sessions

**Multi-Format Output**
- One markdown source → HTML, PDF, slides, diagrams
- Perfect for API docs, user manuals, knowledge bases

## 🎁 What's Included

**Free Tier:**
- Everything you need for open source projects
- HTML generation, search, dark mode
- Diagrams and slides
- MIT licensed

**Professional ($99 one-time):**
- Branded PDFs with custom covers
- White-label customization
- Commercial license

**Enterprise ($499 one-time):**
- Custom integrations
- SLA guarantees
- Training sessions

## 🚀 Get Started

```bash
git clone https://github.com/nexusos/docs-platform
npm install
npm run build
```

That's it! Your docs are ready.
